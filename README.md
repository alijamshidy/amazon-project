# پروژه آمازون (Amazon Project)

## 📌 توضیحات پروژه

این پروژه یک وب‌سایت فروشگاهی مشابه آمازون است که با استفاده از HTML، CSS و JavaScript پیاده‌سازی شده است. هدف از این پروژه، تمرین و یادگیری مفاهیم طراحی وب و توسعه فرانت‌اند است.

## 🧰 ویژگی‌های اصلی

- **صفحه اصلی (index.html):** نمایش محصولات و دسته‌بندی‌ها.
- **صفحه سفارشات (orders.html):** نمایش لیست سفارشات کاربران.
- **صفحه پیگیری (tracking.html):** امکان پیگیری وضعیت سفارشات.
- **استایل‌ها (styles/):** فایل‌های CSS برای طراحی صفحات.
- **اسکریپت‌ها (scripts/):** فایل‌های JavaScript برای تعاملات و منطق صفحه.
- **تصاویر (images/):** تصاویر محصولات و آیکون‌ها.
- **بک‌اند (backend/):** کدهای مرتبط با سرور و پایگاه داده (در صورت وجود).
- **داده‌ها (data/):** فایل‌های JSON یا داده‌های استاتیک برای محصولات و سفارشات.

## 🚀 نحوه راه‌اندازی پروژه

1. پروژه را کلون کنید:
   ```bash
   git clone https://github.com/alijamshidy/amazon-project.git
   ```

2. وارد پوشه پروژه شوید:
   ```bash
   cd amazon-project
   ```

3. برای مشاهده پروژه در مرورگر، فایل `index.html` را باز کنید.

## 💡 نحوه استفاده

- برای مشاهده صفحه اصلی، فایل `index.html` را در مرورگر باز کنید.
- برای مشاهده سفارشات، به صفحه `orders.html` بروید.
- برای پیگیری وضعیت سفارشات، از صفحه `tracking.html` استفاده کنید.

## 🤝 مشارکت در پروژه
